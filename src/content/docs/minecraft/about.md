Welcome to Orange MC, the best anarchy Minecraft server where chaos meets creativity. In this lawless world, there are no rules and no limits to what you can achieve. Build, destroy, raid, and explore a vast, ungoverned landscape where your imagination and survival skills are the only boundaries.



## Commands

| Command                                   | Description                                             |
| ----------------------------------------- | ------------------------------------------------------- |
| `/register <password> <password>`         | Register your account - type this after the captcha     |
| `/login <password> <password>`            | Log in, typing your password two times                  |
| `/captcha <the code it gave>`             | Confirms that you are not a robot                       |
| `/changepassword <old> <new>`             | Type your old password, then the new one two times      |
| `/sethome <name>`                         | Sets your home for teleportation                        |
| `/home <name>`                            | Teleports you to your beloved home/base                 |
| `/delhome <name>`                         | Deletes the teleport to that home                       |
| `/msg <player>`                           | Private message a player without others seeing          |
| `/autosort`                               | Sorts the items in a chest, similar to Terraria         |
| `/stuck`                                  | Unstucks you from stucky places                         |
| `/escape`                                 | Same as `/stuck`, with a different name                 |
| `/clean`                                  | This command cleans items around you that lay on ground |
| `/premium`                                | Makes you vertified user. Doesn't require you to login  |
| `/freemium`                               | The offline account conversion (offline login)          |
| `/tpa` `/tpaccept` `/tpadeny` `/tpacancel`| Teleportation command for users                         |
| `/spawn`                                  | Teleports you to spawn                                  |

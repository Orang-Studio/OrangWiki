| Plugin           | What it does |
| ---------------- | ------------ |
| AntiPopup        | Hides the client-side pop-up on join. |
| Autosort         | Adds a command that sorts chests. |
| DiscordSRV       | Bridges chat from Minecraft to Discord and vice versa. |
| Killc            | `/kill` yourself. |
| LogFilter        | Removes logs that aren't needed. |
| LuckPerms        | Fixes Minecraft permissions. |
| Simple Voice Chat| Adds server-side voice chat - for this you need the [mod](https://modrinth.com/plugin/simple-voice-chat/versions). |
| RMotd            | Sets a random message of the day. |
| SimpleHomes      | Adds home teleportation. |
| SkinsRestorer    | Gives you your vanilla skin on a cracked server. |
| Stuck            | Unstucks you from places. |
| TabCompleteFilter| Filters inaccessible commands. |
| TAB              | Enables a custom tab bar. |
| ViaBackwards, ViaRewind & ViaVersion | Enable support for old versions of Minecraft. |
| SetSpawn         | Sets /spawn. |
| SimpleTpa        | For players teleportation mod |
| ClearDrops       | Allows you to clean items around you, except the valuable ones! |


These are community-based plugins and all of them are free. Some plugins may not be listed for security reasons (exploits).

## Homemade plugins

- **RMotd** - Random message of the day system to keep server greetings fresh. [Download](https://github.com/adasjusk/RMotd)
- **killc** - Lightweight `/kill` yourself command plugin. [Download](https://github.com/adasjusk/KillC)
- **stuck** - `/stuck` rescue command for players who get stuck. [Download](https://github.com/adasjusk/Stuck)
- **ClearDrops** - `/clean` cleans the items around you. [Download](https://github.com/adasjusk/ClearDrops)

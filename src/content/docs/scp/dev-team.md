Mail **[software@oranges.lt](mailto:software@oranges.lt)** - this sends a mail to our development team.

## Contact examples

### Bugs

```txt
Title: [Bug Found] Name of bug
Subject: Mail provided up

Hello, Orange Devs
So i found that bug and etc...
(optional discord username):
Writer Name
```

## Frequently Asked Questions

### Installation
**Q: Where can I download OrangLauncher?**  
A: See [Installation](/oranglauncher/user-guide/#installation) for official download links.

**Q: Can I install on Windows?**  
A: Yes, download from [GitHub Releases](https://github.com/Orang-Studio/OrangLaunch/releases).

**Q: Which Linux distributions are supported?**  
A: Arch (AUR), and any Linux with Python 3.13*.

### Usage
**Q: How do I install mods?**  
A: See [Managing Instances](/oranglauncher/user-guide/#managing-instances) section.

**Q: Can I import modpacks?**  
A: Yes, see [Installing Modpacks](/oranglauncher/user-guide/#installing-modpacks).

**Q: How do I backup saves?**  
A: See [Managing Instances](/oranglauncher/user-guide/#managing-saves) in User Guide.

### Modding
**Q: How do I create a plugin?**  
A: See [Plugin Development](/oranglauncher/modding/#plugin-development).

**Q: What mod loaders are supported?**  
A: Fabric, Forge, and Quilt. See [Mod Loader Support](/oranglauncher/modding/#mod-loader-support).

### Development
**Q: How do I contribute to OrangLauncher?**  
A: See [Build Tutorial](/oranglauncher/building/) to compile from source.

**Q: How do I report bugs?**  
A: Visit [GitHub Issues](https://github.com/Orang-Studio/OrangLaunch/issues).

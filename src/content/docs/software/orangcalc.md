**OrangCalc** is a lightweight, responsive desktop calculator built for daily calculations, programmer math, unit conversions, and currency tracking.

## Features

- **Standard & Scientific Math**: Basic arithmetic, trigonometric functions, exponents, roots, and logarithms.
- **Persistent Calculation History**: Keep track of previous operations, copy past answers, and clear session logs.
- **Live Exchange Rates**: Built-in currency converter with updated foreign exchange rates cached locally.
- **Custom Definitions**: Define and store variables or reusable mathematical formulas.
- **Fast Startup & Minimal Resource Usage**: Native performance with no background overhead.

**OrangWallpapers** is a curated wallpaper manager that brings high-resolution artwork, community photos, and minimal themes straight to your desktop.

## Features

- **High-Resolution Collections**: Browse 4K and ultrawide wallpapers curated across nature, anime, minimal, and gaming genres.
- **Dynamic Scheduled Rotation**: Automatically rotate desktop backgrounds based on time intervals, sunrise/sunset, or system theme (light/dark mode).
- **Multi-Monitor Support**: Set separate backgrounds per monitor or span panoramic scenes seamlessly across displays.
- **Offline Favorites & Collections**: Download and bookmark wallpapers for offline rotation.
- **Native Desktop Integration**: Supports Windows 11/10/8.1

## Usage

Launch OrangWallpapers from your application launcher or terminal:

```bash
orangwallpapers
```

Choose a collection, preview in full resolution, and click **Apply as Wallpaper**.
